Normal Enough

A small tool that publishes an animated YouTube channel.

What this is

Normal Enough is a personal, single-operator project. It is a program that produces short animated videos — simple stick-figure animation, a narrated voice track and word-by-word subtitles — and uploads them to one YouTube channel: @itsnormalenough.

The videos are short comedic stories about ordinary adult life: work, meetings, commutes, the small absurdities of a normal week. The scripts are written by a person. The program handles everything after that: it plans the scenes, renders the animation, generates the narration, writes the title and description, and publishes the result.

What the application does with Google APIs

The application uses the YouTube Data API v3 for exactly two things, both on the operator's own channel:

  • Uploading a finished video to the channel, with its title, description, tags, category and privacy setting. (youtube.upload)
  • Reading the authorised channel's name and handle, to confirm that the upload is going to the intended channel and not to another account that happens to be signed in. (youtube.readonly)

It does not read, modify or delete existing videos. It does not access any channel other than the one that authorised it. It has no users other than the operator, and no sign-in of any kind for anyone else.

Who it is for

Nobody but its author. This is not a product, a service or an app that other people install. It runs on one server and publishes to one channel. This page exists because Google requires a public home page for applications that request access to the YouTube API.
