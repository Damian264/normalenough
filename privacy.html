Privacy Policy

Normal Enough · last updated 7 September 2026

Summary

Normal Enough is a personal tool operated by one person, for one YouTube channel. It has no users other than its operator. It does not collect, store, process or share personal data belonging to anyone else, and it has no mechanism by which anyone else could sign in or submit data.

Google user data the application accesses

The application requests access to the operator's own Google Account through Google OAuth 2.0, using these scopes and no others:

  • https://www.googleapis.com/auth/youtube.upload — used solely to upload finished video files, together with their title, description, tags, category and privacy status, to the operator's own YouTube channel.
  • https://www.googleapis.com/auth/youtube.readonly — used solely to read the authorised channel's identifier, title and handle, in order to verify that an upload is going to the intended channel. This is a safety check: it prevents the application from publishing to a different account that may have been selected by mistake during authorisation.

How that data is used

The channel identifier, title and handle are read at the moment of an upload, compared against the expected channel, and then discarded. They are not stored beyond the current run, except for the channel name and identifier, which are written once into a local credentials file so the operator can see which channel was authorised.

The videos and their metadata are created by the application itself. They do not contain personal data.

How that data is stored

  • The OAuth refresh token is stored in a single file on the operator's own server, readable only by the operator's user account. It is never transmitted anywhere except to Google's own token endpoint, in order to obtain the short-lived access tokens needed for an upload.
  • No database exists. No analytics, tracking, advertising or profiling of any kind is performed.
  • No Google user data is stored on any third-party service.

Sharing

Google user data is never shared, sold, transferred or disclosed to any third party. It is not used to train any model. It is not used for advertising. There is no third party involved: the data travels only between the operator's own server and Google.

Retention and deletion

The refresh token is kept only for as long as the channel is in operation, and is deleted when the application stops being used. The operator can revoke the application's access at any time from Google Account permissions, which immediately and permanently invalidates the stored token.

To request deletion of any data, contact the address below. In practice there is nothing to delete other than the operator's own token.

Limited Use

Normal Enough's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Children

The application is not directed to children and does not knowingly process any data concerning children. The videos it publishes are declared as not made for kids.

Changes

If this policy changes, the updated version will be published on this page with a new date.
